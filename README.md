# 📱🌿 AgriSmart - Application de Farming Intelligent

## 📝 Description
AgriSmart est une application mobile dédiée aux agriculteurs, conçue pour les aider à gérer leurs cultures facilement, même sans connexion Internet.

Elle offre des fonctionnalités essentielles comme :
- La détection des maladies des plantes 📸  
- Des conseils agricoles 🌱  
- La gestion du calendrier agricole 📅  

## 🎯 Fonctionnalités
- 📸 Scan Plant : Prendre une photo d’une plante pour détecter les maladies  
- 🌿 Farming Tips : Conseils adaptés selon le type de culture  
- 📅 Calendar : Organisation des périodes de semis, arrosage et récolte  
- 🌾 My Crops : Gestion et suivi des cultures  
- 📂 Mode Offline : Fonctionne sans connexion Internet
